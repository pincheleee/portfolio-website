# Portfolio Website

Personal portfolio site for Robert Monterroso -- static site with projects, resume, and blog.

## Stack
- HTML/CSS (no framework, no build step)
- Google Fonts (Roboto), Material Symbols icons
- Hosted on Cloudflare Pages (pinchelee.com)

## Commands
- `open index.html` -- view locally
- `python3 -m http.server` -- local dev server
